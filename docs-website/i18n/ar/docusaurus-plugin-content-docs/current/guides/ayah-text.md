# نص الآية (التفاسير والترجمات)

يعيد `GET /ayahs/{ayah_key}/?assets=…` نص عدة أصول نصية (تفاسير وترجمات وأي أصل نصي آخر له وسم) لآية واحدة في طلب واحد.

```bash
curl -H "X-API-Key: $ITQAN_API_KEY" \
  "{{API_BASE}}/ayahs/2:255/?assets=tafsir-al-muyassar,saheeh-international"
```

## المعاملات

| المعامل | الموضع | الوصف |
|---|---|---|
| `ayah_key` | المسار | `surah:ayah`، مثل `2:255`. |
| `assets` | الاستعلام | **مطلوب.** الأسماء المختصرة (slugs) للأصول النصية المطلوبة، مفصولة بفواصل (`?assets=a,b`) و/أو مكررة (`?assets=a&assets=b`). 20 على الأكثر. لا يُعاد إلا هذه الأصول، وبهذا الترتيب؛ والاسم المكرر يُعاد مرة واحدة. |
| `to` | الاستعلام | اختياري: رقم آخر آية في نطاق داخل السورة نفسها، مثل `/ayahs/2:1/?assets=…&to=5` للآيات 2:1–2:5. 50 آية على الأكثر. |

الأسماء المختصرة للأصول هي أسماء الحزم الظاهرة في مكتبة الأصول وفي `itqan browse`.

## الاستجابة

```json
{
  "surah_number": 2,
  "from_ayah": 255,
  "to_ayah": 255,
  "assets": [
    {
      "slug": "tafsir-al-muyassar",
      "name_en": "Al-Muyassar",
      "name_ar": "التفسير الميسر",
      "category": "text",
      "tags": ["tafsir"],
      "template": "ayah",
      "language": "ar",
      "version": "1.2",
      "columns": [{ "key": "text", "label_en": "Text", "label_ar": "النص" }],
      "rows": [
        {
          "start": { "ayah_key": "2:255", "word_position": null },
          "end": { "ayah_key": "2:255", "word_position": null },
          "cells": { "text": "…" }
        }
      ]
    }
  ]
}
```

- يُقدَّم كل أصل في **إصداره المنشور** وبـ**لغته المصدر** (`version` و`language`).
- يسرد `columns` أعمدة النص في الأصل بترتيبها في الملف؛ وفي `cells` مدخل لكل مفتاح عمود (`""` حين تكون الخلية فارغة). استخدم التسميات عناوينَ للأعمدة.
- `rows` هي وحدات الأصل التي تغطي الآيات المطلوبة، بترتيب المصحف. الأصل الذي لا نص له لتلك الآيات يُعاد أيضًا، مع `rows: []`.

### الصفوف حسب القالب

يبيّن `template` ما يمثله الصف الواحد:

| `template` | صف واحد لكل | `start` / `end` |
|---|---|---|
| `ayah` | آية | الآية نفسها |
| `word` | كلمة | الكلمة نفسها (`word_position` موضعها في الآية) |
| `ayah_group` | مجموعة آيات كتب لها الناشر نصًا واحدًا | أول آية في المجموعة وآخرها؛ وقد تبدأ قبل الآيات المطلوبة أو تنتهي بعدها |
| `word_group` | مجموعة كلمات | أول كلمة في المجموعة وآخرها |

الأصول المبنية على السور أو الصفحات ليس لها وحدة لكل آية، فتُرفض (`asset_not_ayah_based`).

## الوصول

تتبع نقطة النهاية قواعد نقاط التلاوات نفسها:

- الأصول المفتوحة لا تحتاج مفتاح API.
- الأصول المقيدة تحتاج مفتاح API (`X-API-Key`) يملك صاحبه طلب وصول مقبولًا لـ**كل** منها. اطلب الوصول من صفحة الأصل في مكتبة الأصول.

يُحسب كل طلب استدعاءً واحدًا للواجهة في تقارير الاستخدام، ولا يُقسَّم على الأصول التي يعيدها.

## الأخطاء

الأخطاء تخص الطلب كله. حين يتعلق الخطأ بأصول بعينها، يسرد `extra.assets` أسماءها المختصرة:

```json
{
  "error_name": "access_denied",
  "message": "You don't have an approved access request for these assets.",
  "extra": { "assets": ["restricted-tafsir"] }
}
```

| HTTP | `error_name` | متى |
|---|---|---|
| 400 | `assets_required` | `assets` غائب أو فارغ |
| 400 | `too_many_assets` | أكثر من 20 اسمًا مختصرًا |
| 400 | `invalid_ayah_range` | `to` قبل الآية الأولى، أو بعد نهاية السورة، أو النطاق أطول من 50 آية |
| 400 | `asset_not_text` | اسم مختصر لأصل ليس أصلًا نصيًا (تلاوة، مصحف، خط، …) |
| 400 | `asset_not_ayah_based` | اسم مختصر لأصل نصي مبني على السور أو الصفحات |
| 401 | `authentication_required` | طُلب أصل مقيد دون مفتاح API |
| 403 | `access_denied` | صاحب مفتاح API لا يملك وصولًا مقبولًا غير منتهٍ إلى أصل مقيد |
| 404 | `ayah_not_found` | مفتاح الآية مشوَّه أو الآية غير موجودة |
| 404 | `asset_not_found` | الاسم المختصر غير معروف، أو الأصل غير متاح عبر الواجهة، أو ليس له إصدار منشور |

حين تفشل عدة فحوص، يُعاد أولها بهذا الترتيب: `asset_not_found`، `asset_not_text`، `asset_not_ayah_based`، `authentication_required`، `access_denied`.

## التخزين المؤقت

لا تحفظ الذواكر المؤقتة المشتركة (مثل شبكات توزيع المحتوى والوكلاء) الاستجابات أبدًا، فالأصل الذي يصبح مقيدًا يتوقف تقديمه من الطلب التالي. الاستجابات المكوّنة من أصول مفتوحة فقط تأتي بـ `Cache-Control: private, max-age=300`، بمفتاح API أو دونه: يجوز لعميلك وحده إعادة استخدامها 5 دقائق. والاستجابة التي فيها أي أصل مقيد تأتي بـ `private, no-cache`. قد يستغرق ظهور إصدار منشور جديد حتى 5 دقائق.
